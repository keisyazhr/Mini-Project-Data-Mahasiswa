## Deskripsi
Program Data Mahasiswa adalah aplikasi sederhana berbasis Java yang berjalan melalui Command Line Interface (CLI). Program ini digunakan untuk memasukkan dan menampilkan data mahasiswa serta menentukan status kelulusan berdasarkan nilai.

## Fitur
- Memasukkan nama, NIM, dan nilai mahasiswa.
- Membuat minimal tiga objek mahasiswa.
- Menampilkan data mahasiswa.
- Menentukan status kelulusan menggunakan percabangan if-else.

## Materi Java yang Digunakan
- Variable dan tipe data
- Scanner
- If-else
- Loop
- Class dan object
- Method

## Cara Menjalankan
Jalankan perintah berikut melalui terminal pada folder proyek:

```bash
javac Main.java
java Main
```
